# Issue Tracker

## Gitea Issues

此项目使用 Gitea Issues 作为任务来源。

## 可交给 Agent 处理的 Issue 类型

- Bug fix：能定位到具体文件
- UI/前端改动：有明确的组件或样式目标
- 文档更新：已有内容参考
- 重构：不涉及架构变更

## 需要人先处理的 Issue

- 涉及 `vite.config.ts`、`tailwind.config.js` 修改
- 涉及 `package.json` dependencies 变更
- 架构决策类改动
