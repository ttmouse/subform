# Working Boundaries

## Allowed

- 修改 `src/components/`、`src/jsx-components/` 下的组件
- 修改 `src/App.tsx` 布局和路由
- 修改 `src/index.css` 全局样式
- 添加新组件到现有目录

## Requires Approval

- 修改 `vite.config.ts`
- 修改 `tailwind.config.js`
- 修改 `package.json` dependencies
- 修改 `index.html`

## Forbidden

- 不允许修改 `node_modules`
- 不允许修改 `dist/` 构建输出
- 不允许修改数据模型（无后端，但禁止破坏 state 结构）
- 不允许重写整个模块
